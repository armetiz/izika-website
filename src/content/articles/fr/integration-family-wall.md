# Family Wall - Assistant familial

Synchroniser votre compte Family Wall avec izika vous permet d'obtenir automatiquement vos indemnités kilométriques depuis cette application de gestion de votre quotidien familial.

## Procédure de synchronisation

Si vous souhaitez que les événements de FamilyWall soient visibles sur votre compte izika, veuillez suivre les étapes ci-dessous :

- Allez dans l'app FamilyWall
  - appuyez sur la section **Calendrier**
  - appuyez sur l'icône en haut à droite pour accéder aux paramètres du calendrier.
  - appuyez sur le 1er calendrier avec le nom de votre cercle pour accéder aux options
  - générez un iCal et copiez le lien.
- Rendez-vous dans les [paramètres](https://go.izika.com/app/settings) de l'application izika
  - cliquez sur **Ajouter un agenda**
  - puis sur **Ajouter un agenda via un lien ICS**
  - collez le lien obtenu depuis l'application FamilyWall puis **validez**
