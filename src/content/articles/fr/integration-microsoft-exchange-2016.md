# Connecter Microsoft Exchange 2016 à izika

Microsoft Exchange Server permet de publier votre calendrier au format ICS. Ce lien ICS est utilisé par izika pour importer vos rendez-vous et calculer automatiquement vos indemnités kilométriques.

## Procédure

1. Connectez-vous et accédez à votre calendrier Microsoft Exchange 2016
2. En haut à droite, cliquez sur la **roue crantée** puis **Options**
3. Dans le volet gauche, sélectionnez **Calendrier** → **Calendriers partagés** → **Publier le calendrier**
4. Sélectionnez le calendrier à exporter, choisissez les autorisations **Tous les détails** et cliquez sur **Enregistrer**
5. Copiez le lien **ICS** (clic droit → Copier l'adresse du lien)
6. Dans izika, allez dans **Paramètres** → **Agendas**
7. Cliquez sur **Ajouter un agenda via un lien ICS**, collez le lien et validez

## Cas pratique : partage Exchange bloqué par la DSI

Si la publication de calendrier est verrouillée par votre direction informatique, voici une solution de contournement :

Pour chaque rendez-vous professionnel, invitez votre adresse email personnelle (Gmail par exemple) en tant que participant. Le rendez-vous apparaît alors dans votre agenda Gmail, que vous connectez à izika à la place d'Exchange.

Avantage : vous contrôlez précisément quels rendez-vous alimentent izika en n'invitant votre email personnel que sur les déplacements à déclarer.
