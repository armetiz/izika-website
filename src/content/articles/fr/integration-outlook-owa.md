# Connecter Outlook Web Access (OWA) à izika

Outlook Web Access (Outlook Live / Hotmail) permet de publier votre calendrier via un lien ICS. Ce lien est utilisé par izika pour importer vos rendez-vous et calculer automatiquement vos indemnités kilométriques.

## Procédure

1. Connectez-vous à votre calendrier [Outlook OWA](https://outlook.live.com)
2. En haut à droite, cliquez sur la **roue crantée** puis **Options**
3. Dans le volet gauche, sélectionnez **Calendrier** → **Calendriers partagés** → **Publication de calendrier**
4. Dans la zone **Afficher la disponibilité, les titres et les emplacements**, cliquez sur **Créer**
5. Copiez le lien **ICS** (clic droit → Copier l'adresse du lien)
6. Dans izika, allez dans **Paramètres** → **Agendas**
7. Configurez vos adresses favorites et vos véhicules
8. Cliquez sur **Ajouter un agenda via un lien ICS**
9. Collez le lien ICS et validez
